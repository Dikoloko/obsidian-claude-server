# obsidian-claude-server: werkregels voor Claude Code

Aangepaste kopie van obsidian-web-mcp die Claude (app, web, gsm, CarPlay) toegang geeft tot een eigen Obsidian-vault, via een Windows-pc en een Cloudflare-tunnel.

- Installeren voor een gebruiker: volg `INSTALLATIE-WINDOWS.md`. De gebruiker heeft meestal geen technische kennis: doe het technische werk zelf en leg uit in gewone taal.
- Wat er anders is dan bij de maker en waarom: `WIJZIGINGEN.md`.
- Raak de controles in `tests/test_fork_hardening.py` niet aan om een test groen te krijgen.
- Wijzig nooit iets in de vault van de gebruiker tijdens het installeren.
